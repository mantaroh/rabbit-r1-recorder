# 記録の削除（PC画面・カメラ・音声）

2026-10-07 JST

## 決めたこと

- 日ビューのカードに削除ボタンを付ける（画像1枚・音声1件ごと）。
- 日ビューの「時間帯を削除」で、その日の時間帯と種類（PC画面／カメラ（R1・眼鏡）／音声）を指定してまとめて消せる。先に件数を確認してから消す。
- 消したらすぐ完全に消す。R2 の実体（キャプション用の縮小版も含む）、D1 の行、検索索引（既存の DELETE トリガー）。ごみ箱は作らない。
- 削除は admin だけ（ブラウザは Cloudflare Access 経由で admin）。端末・PC・エージェントの資格情報では消せない。

## 消す順番

R2 → D1。`/v1/admin/reindex` は R2 にあって D1 に行がない音声を復元するので、D1 を先に消して R2 で失敗すると戻ってくる。

## 再送で戻ってこないようにする

| 残すもの | テーブル | 断る再送 |
| --- | --- | --- |
| 消した ID | `deleted_media` | R1・PC の再送、眼鏡の同じ動画の再取り込み |
| 消した時間帯 | `deleted_ranges` | R1 がオフラインで溜めていて、消したあとに届いた録音・写真 |

断るときは `200 {deleted: true}` を返す。R1 は 2xx 以外を再送し続けるため。PC は受領の `photo_id` と `source` を照合するので、その2つも返す。

時間帯の記録は実装中に追加した（ID だけでは、まだ届いていない録音を断れない）。

## API

| メソッド | パス | 内容 |
| --- | --- | --- |
| DELETE | `/v1/photos/<id>` | 写真1枚 |
| DELETE | `/v1/segments/<id>` | 音声1件 |
| POST | `/v1/admin/delete-range?from=&to=&kinds=desktop,camera,audio[&dry_run=1]` | 時間帯。[from, to)、24時間まで。1回500件で、`remaining` が0になるまで呼び直す |

音声の時間帯削除は、日ビューに出ない `kind='query'` も含める。

## 影響

- `nudge_log.photo_id` の行は残り、画像だけ表示されなくなる。
- メディアは `private, max-age=31536000, immutable` なので、閲覧したブラウザのキャッシュには残る。
- キャプション・文字起こしの処理中に消した場合は、R2 にないので何もせず終わる。

## 却下した案

| 案 | 理由 |
| --- | --- |
| 論理削除 | 中身が残る |
| 7日間のごみ箱 | 同上。誤削除は確認ダイアログで防ぐ |
| MCP からの削除 | エージェントが誤って消すと戻せない |

## 確認したこと

- 単体テスト 109件通過（`test/delete-media.test.ts` を追加）。
- ローカル Worker（`wrangler.desktop-test.jsonc`）で、1件削除・再送の拒否・検索から消えること・時間帯削除・時間帯への遅れた録音の拒否・権限・24時間超の拒否・R2 の縮小版の削除を確認。
- 日ビューに削除ボタンと「時間帯を削除」が表示されることをスクリーンショットで確認。ダイアログの操作は画面では未確認。
